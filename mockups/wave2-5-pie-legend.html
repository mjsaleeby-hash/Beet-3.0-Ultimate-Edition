Wave 2.5 — pie legend accessibility & contrast sign-off

Reviewed before any XAML is written, per docs/superpowers/specs/2026-08-05-wave-2-5-pie-a11y-design.md. Both themes are shown side by side throughout, not behind a toggle — this sheet is for comparing them, not experiencing one at a time. Data below is the top-10-plus-Other slice list an actual drive would produce; sizes, names and the 11 slice colours (including the Other grey) are the real values already in MainViewModel.PieColors.
The one thing this sheet exists to show: the legend percentage text fails 4.5:1 contrast for all eleven slice colours in light mode, and passes for all eleven in dark mode, against each theme's own SurfaceColor. The fix — painting the percentage in PrimaryTextBrush instead of the slice colour — is a single code path, so it necessarily recolours dark mode too, even though dark had nothing wrong today. Section 1 shows exactly what that trade looks like in both directions before it ships.

1Legend percentage colour — current vs proposed

current paints the percentage in the slice's own FillColor (today's behaviour). proposed paints it in PrimaryTextBrush for every row. The ratio under each current-column percentage is its measured contrast against that theme's SurfaceColor, from the spec's table.
